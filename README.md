# jakkzz.github.io

Personal site. One page, hand-written HTML and CSS.

- **No framework, no build step, no dependencies** — edit `index.html` and push
- **No external requests** — system font stack, inline CSS, SVG data-URI favicon
- Dark mode via `prefers-color-scheme`, responsive down to 320px
- SEO: semantic HTML, Open Graph, Twitter cards, JSON-LD `Person` schema, sitemap, canonical URL

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000
